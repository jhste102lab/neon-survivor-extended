# 릴리즈 노트 — 2026-07-07

## 핵심 변경

- **차원 균열 등장 방식 개편**
  - 10분 이후 보스 처치에 묶이지 않고, 2분마다 30% 확률로 차원 균열이 등장합니다.
  - 3회 연속 실패하면 다음 체크에서 균열이 확정 등장합니다.
  - 기록 보관소, 도박장, 점액, 프리즘 차원이 랜덤으로 등장합니다.

- **차원 보상 조정**
  - 이벤트 완료 보상은 강한 단일 보상 대신, 약한 보상 2개 중 1개를 선택하는 방식으로 변경했습니다.
  - 도박장 차원에는 현재 체력 절반을 대가로 60초 동안 공격력/이동속도/재생 중 하나가 2배가 되는 거래 보상을 추가했습니다.

- **시작 전 아이템 드롭 필터 추가**
  - 일반 적에게서 나오는 치킨, 자석, 폭탄 드롭을 시작 화면에서 켜고 끌 수 있습니다.
  - 꺼둔 아이템도 보스 보상에서는 계속 등장할 수 있습니다.

- **보호막 수치 표시 추가**
  - 플레이어에게 적용 중인 보호막 양을 HP 바 옆에 표시합니다.

## 전투/보스 개선

- 10분 이후 보스 패턴에 꼭짓점 기반 레이저 패턴을 추가했습니다.
- 일부 후반 보스가 새로 태어나는 적에게 짧은 방어 오라를 부여합니다.
  - 방어 오라를 받은 적은 받는 피해가 감소하고 관통 탄을 더 빨리 소모합니다.
  - 대신 보스는 해당 패턴 중 짧게 취약해집니다.
- 무기 봉인 보스 주변에 탱커가 과도하게 몰리면 일부 탱커가 응집체 미니 보스로 합쳐져 길막 상황을 줄입니다.
- 후반 일반 보스 일부가 점액 장판을 남기는 패턴을 사용할 수 있습니다.
  - 점액 지속시간은 1분이 아닌 짧은 시간으로 제한해 화면 잠김을 줄였습니다.
- 폭탄 누적 판정 추가: 보스가 아닌 적은 폭탄에 8회 누적 피격되면 처치됩니다.

## UI/가독성

- 도감 상세 화면에 적과 보스의 기본 HP, 속도, 피해량, XP 정보를 추가했습니다.
- 보스 수치는 실제 전투에서 시간과 후반 루프에 따라 증가한다는 안내를 추가했습니다.

## 버그 수정

- 일시정지 후 다시 시작했을 때 검은 화면이 남을 수 있는 문제를 완화했습니다.
  - 재개/복구 시 캔버스 크기와 렌더 프레임을 강제로 갱신합니다.
