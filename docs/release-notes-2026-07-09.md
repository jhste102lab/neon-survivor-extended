# 릴리즈 노트 — 2026-07-09

## 핵심 변경

- **이벤트와 차원균열 분리**
  - 기존 필드 이벤트는 기존 보상 흐름을 유지하고, 이벤트 균열은 “차원균열”과 혼동되지 않도록 균열장 표현으로 정리했습니다.
  - 10분 이후 발생하는 차원균열은 대기 포털 없이 짧은 경고 후 랜덤 차원 시련으로 자동 진입합니다.
  - 차원균열 미션을 클리어하거나 붕괴되면 원래 전장 상태로 복귀합니다.

- **10분 문지기 안내 정리**
  - 실제 동작과 맞지 않던 “10분 균열 문지기” 안내를 도감/문서에서 제거했습니다.
  - 보스 처치 뒤 남던 방어 오라 잔재는 제거해, 보스 처치 보상감이 방해받지 않도록 했습니다.

- **도박장 거래 5종 확장**
  - 도박장 거래가 현재 체력 절반을 지불하고 60초 버프를 얻는 구조는 유지합니다.
  - 기존 공격력/이동속도/재생 2배에 더해 보호막 내구도 2배, 치명타율 1.5배 결과를 추가했습니다.

## 후반 성장/밸런스

- **자석 장갑 후반 연계 강화**
  - 10분 이후 자석 중력장에 자석 장갑 레벨 보정을 적용합니다.
  - 자석 장갑 1레벨당 중력장 둔화가 3%p, 범위가 4% 증가합니다.
  - 보스 둔화는 별도 상한을 적용해 보스 압박이 무력화되지 않도록 했습니다.

- **플레이 전 런 설정 추가**
  - 최대 무기 수를 기본/10/15/20/전체로 설정할 수 있습니다.
  - 선택한 상한 때문에 10/15/20 무기 슬롯 해금을 받지 못하면 해당 단계마다 전체 무기 피해 +10% 보너스를 얻습니다.
  - 몹 수 절반 모드를 추가했습니다. 이 모드는 일반 몹 밀도를 50%로 줄이는 대신 일반 몹 체력/피해량을 1.8배로 올립니다.

## UI/가독성

- **시작 화면 설정 정리**
  - 드롭 필터와 새 런 설정을 시작 화면의 설정 영역으로 묶어, 설정이 늘어나도 화면이 덜 복잡하게 보이도록 했습니다.

- **좌하단 빌드 HUD 수납**
  - 무기/패시브 슬롯 HUD를 접어서 `⚔ 현재/최대` 요약만 볼 수 있습니다.
  - 접힘 상태는 로컬 설정으로 저장됩니다.

- **일시정지 빌드 상세 개선**
  - 일시정지 화면에서 무기/패시브 아이콘을 누르면 해당 항목 설명만 표시됩니다.
  - 개별 무기 이펙트 ON/OFF는 유지하고, 모든 무기 이펙트를 한 번에 켜고 끄는 버튼을 추가했습니다.
  - 보호막 관련 설명은 “보호막 내구도” 표현으로 정리했습니다.

## 랭킹/기록

- **커스텀 런 설정 기록**
  - 랭킹 스냅샷에 드롭 필터, 최대 무기 수, 무기 제한 보너스, 몹 밀도, 몹 스탯 배율을 저장합니다.
  - 랭킹 행과 상세 화면에서 커스텀 설정 여부와 세부 설정을 확인할 수 있습니다.
  - 원격 리더보드 API 정규화에서도 새 설정 필드를 보존합니다.
