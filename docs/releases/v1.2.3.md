# v1.2.3 — 차원 균열 피날레와 20분 엔딩

## 차원 균열 흐름

- 2분에는 30% 확률로 차원 균열이 등장하고, 3분에는 한 번 확정 등장합니다.
- 이후 4분, 6분, 8분 체크와 10분 이후 보스 처치 확정 균열을 지원합니다.
- 균열에 닿으면 기다리지 않고 무작위 정식 차원 시련으로 진입합니다.
- 반복 강제 진입을 제거하고 플레이어가 포탈 진입 여부를 선택하게 했습니다.

## 서로 다른 8개 차원 시련

- 탄막 성운: 외곽 노드 파괴 후 중앙 코어 공격
- 기계 감옥: 활성 발전기를 순서대로 차단
- 중력 우물: 앵커 근처에서 과부하 충전 후 파괴
- 심판자의 결투: 이동/정지 판결을 수행해 방어막 해제
- 역병 정원: 둥지 근처에서 정화 게이지 충전
- 거울 회랑: 표시되는 진짜 거울핵 우선 공략
- 열차 위 전장: 지정 차선으로 이동해 사격선 확보
- 도박장 균열: 세 계약 문 중 하나를 직접 선택해 라운드 진행

입장 시 짧은 브리핑을 제공하고, 전투 중에는 현재 행동만 간결하게 표시합니다. 자동무기는 현재 유효한 차원 목표를 우선 조준합니다.

## 보상과 안정성

- 차원 고유 유물과 일반 성장 카드 2개 중 하나를 선택합니다.
- 차원 클리어 후 보상 화면 오류가 발생해도 게임 진행 상태로 자동 복구합니다.
- 8개 차원의 진입, 규칙 수행, 클리어, 보상 선택, 외부 필드 복귀 경로를 검증했습니다.

## 20분 엔딩과 리더보드

- 20분 생존 시 `NEON DAWN` 엔딩과 크레딧이 재생됩니다.
- 완료 후 런을 종료하거나 계속 플레이할 수 있습니다.
- 20분 클리어 기록에는 리더보드 트로피, 전용 배지, 네온 테두리가 표시됩니다.
- 클라이언트와 서버가 20분 클리어 필드를 함께 검증합니다.

## 조작과 시각 효과

- 모바일 드래그 조이스틱을 유지하면서 화면 터치 위치 자동 이동을 추가했습니다.
- 수동 드래그나 방향 입력 시 자동 이동이 즉시 취소됩니다.
- 네온 폭풍 남은 시간을 고대비 독립 배지로 표시합니다.
- Kenney CC0 Particle Pack에서 엄선한 포탈, 차원 배경, 엔딩 VFX 텍스처를 추가했습니다.
- 시각 효과 수는 런타임 성능 압력에 따라 자동 감소하며 게임 판정에는 영향을 주지 않습니다.

## 런 설정

- 절대 무기 수 제한 대신 전체 무기 종류의 60% 제한을 제공합니다.
- 실제 제한 수는 런 시작 시 고정되어 기록에 포함됩니다.
